# SDN Labs – M2 Networks & Systems (Université d'Évry Paris-Saclay)

Hands-on labs on Software-Defined Networking: network emulation with Mininet,
the OpenFlow protocol, and SDN controllers.

## Lab 1 – Mininet & OpenFlow basics
- Custom topologies written with the Mininet Python API (`topo_fig2.py`, `topo_fig3.py`)
- Connectivity tests and flow table inspection with Open vSwitch

## Lab 2 – SDN controllers
- Tree topologies with Mininet's high-level and low-level APIs
  (`simpletree_highlevel.py`, `simpletree_lowlevel.py`)
- Loop topology (`loop_topology.py`)
- Comparison of three controllers: Ryu, OpenDaylight, ONOS
- OpenFlow traffic captured and analyzed with Wireshark (`lab2/captures/`)

## Lab 3 – POX controller *(in progress)*
- Gateway and multipath routing with POX

## Tools
Mininet · Open vSwitch · OpenFlow · Ryu · OpenDaylight · ONOS · POX · Wireshark · Python
